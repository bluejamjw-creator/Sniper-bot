🚀 Sniper Bot

A crypto & stock breakout scanner with Telegram alerts.

Features

- Scans top crypto pairs (Binance)
- Scans trending stocks (Yahoo Finance)
- Detects breakouts using EMA + volume
- Sends alerts to Telegram
- Runs continuously on Railway

Setup

1. Add environment variables:
   
   - "BOT_TOKEN" = your Telegram bot token
   - "CHAT_ID" = your Telegram chat ID

2. Deploy on Railway

Start

npm start

Status

- ✅ Live scanner
- 🔄 Runs every few minutes
